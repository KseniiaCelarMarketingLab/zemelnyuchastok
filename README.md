# Лендинг: земельные участки, Верхняя Подстепновка

Статический сайт из одной папки, без сборки.

## Файлы
- index.html - вся страница (разметка + стили внутри файла)
- land-aerial.png - аэрофото территории (первый блок)
- plot-306.jpg - схема участка 63:17:0514001:306
- plot-313.jpg - схема участка 63:17:0514001:313

## GitHub
1. Создать репозиторий.
2. Загрузить содержимое этой папки в корень репозитория.
3. GitHub Pages: Settings -> Pages -> Source: Deploy from a branch -> main / root.

## Vercel
1. Vercel -> Add New -> Project -> импортировать репозиторий.
2. Framework Preset: Other. Build Command: пусто. Output Directory: пусто (корень).
3. Deploy.

## Что нужно дописать
- Форма пока только показывает подтверждение. Для приёма заявок подключите обработчик (например Formspree, Telegram-бот или API) в атрибуте onsubmit у формы #lead-form.
- В футере и шапке можно добавить телефон и мессенджеры, когда пришлёте контакты.
