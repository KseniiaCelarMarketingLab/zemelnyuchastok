# Лендинг: участки в Верхней Подстепновке

Все файлы лежат в одной папке, загружайте их в корень репозитория.

## Файлы
- index.html - сайт
- config.js - настройки: телефон, Telegram, MAX, бот для заявок, Метрика, пиксель VK
- app.js - интерактивная карта, калькулятор, формы, аналитика
- politika.html - политика конфиденциальности (152-ФЗ)
- *.jpg - сжатые фото и схема

## Что настроить в config.js
1. max - ссылка на ваш профиль в MAX. Пока поле пустое, кнопка MAX открывает окно с номером телефона для поиска в MAX.
2. tgBotToken и tgChatId - заявки будут приходить в Telegram мгновенно:
   - напишите @BotFather → /newbot → скопируйте токен;
   - напишите своему боту любое сообщение (обязательно);
   - узнайте свой chat_id у @userinfobot.
3. metrikaId - создайте счётчик на metrika.yandex.ru и включите Вебвизор.
   Цели (тип «JavaScript-событие»): lead, phone_click, tg_click, max_click, lot_pick.
4. vkPixelId - пиксель из кабинета VK Рекламы (ads.vk.com → Сайты). С ним кампании оптимизируются под заявки, а не под клики.

## Почта
Дублирующая отправка идёт на sm3@ak74.pro через FormSubmit. После первой заявки на почту придёт письмо активации - нажмите кнопку в нём. Проверьте папку «Спам».

## Реклама VK
Добавляйте к ссылке метки: ?utm_source=vk&utm_campaign=название - они придут в заявке.
